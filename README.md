## Download

Download the current release candidate from [GitHub Releases](https://github.com/RedRiveRR/RedRiveRR-GPS-Spoofer/releases/tag/v1.1.0-rc.3).

Only the macOS DMG and its SHA-256 checksum are provided as uploaded Release assets. This repository contains distribution documentation and branding only.

> **macOS security notice:** RC3 is unsigned and unnotarized. If macOS says the developer cannot be verified, verify the DMG checksum and follow the [English Gatekeeper instructions](README.en.md#macos-gatekeeper-warning) or [Turkish Gatekeeper instructions](README.tr.md#macos-gatekeeper-uyarısı). Do not disable Gatekeeper or remove quarantine in Terminal.
