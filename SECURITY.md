# Security Policy

## Reporting A Vulnerability

Do not disclose suspected vulnerabilities, private device information, license
keys, personal location data, or security-sensitive logs in a public issue.

Send a private report to `mertkzlrmk@yandex.ru` with:

- the affected release version;
- a concise description and reproduction steps;
- expected and observed behavior;
- sanitized logs or screenshots, when useful.

Remove tokens, license material, device identifiers, Apple account information,
and precise personal locations before sending evidence.

## Scope

Security reports are accepted for the latest published release candidate. This
public repository is a binary distribution repository and does not provide
source code. Please allow time for investigation before public disclosure.
